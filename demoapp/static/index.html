Kill-switch — is each component necessary?

Turn a component off and the world is rebuilt for real through the same core cycles. Watch stale knowledge, poison, or footprint climb.

Seeded offline simulation: every flip rebuilds an in-memory demo world (it never reads or mutates live fleet memory). Demo tuning: fleet chatter is written at low importance and the token budget sits just below the footprint, so metabolic forgetting prunes chatter while runbook fixes survive — a documented demonstration choice, not an experimental result.
